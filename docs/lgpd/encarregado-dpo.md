# Encarregado pelo Tratamento de Dados Pessoais (DPO)

**Projeto:** Automação Local de WhatsApp para Prospecção B2B
**Data:** 2026-10-01

## Identidade e Informações de Contato do DPO
Neste projeto, em sua fase de MVP operado por uma única pessoa (o Admin), as responsabilidades do Encarregado pelo Tratamento de Dados Pessoais (DPO) são assumidas pelo próprio Admin/Operador do sistema, até que o volume exija uma nomeação separada.

- **Nome:** Admin do Sistema
- **E-mail de Contato:** (A ser preenchido)
- **Atribuições Principais:**
  - Receber e atender requisições dos titulares (leads).
  - Prestar esclarecimentos sobre a base legal utilizada (Legítimo Interesse).
  - Garantir o cumprimento do opt-out imediato.
  - Avaliar riscos e reportar incidentes de segurança, caso ocorram.

## Procedimentos Internos
Sempre que houver uma solicitação de titularidade, o DPO deverá agir conforme descrito no documento de Canal de Atendimento ao Titular.
