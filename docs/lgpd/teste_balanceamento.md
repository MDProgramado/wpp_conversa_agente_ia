# Teste de Proporcionalidade (Legitimate Interests Assessment - LIA)

**Projeto:** Automação Local de WhatsApp para Prospecção B2B
**Base Legal:** Legítimo Interesse (Art. 7º, IX da LGPD)

## 1. Teste de Finalidade (Purpose Test)
**Qual é o interesse legítimo perseguido?**
Prospecção ativa (B2B) para venda de serviços digitais (sites, sistemas, automações). A atividade é essencial para a operação comercial e expansão de mercado do controlador.

## 2. Teste de Necessidade (Necessity Test)
**O tratamento é necessário para alcançar a finalidade?**
Sim. A abordagem via WhatsApp é o canal mais eficaz de conversão direta. Os dados coletados são os mínimos necessários: nome e telefone (eventualmente e-mail/cargo), todos de contato corporativo/profissional. O uso da automação é necessário para gerenciar o volume sem perder a qualidade da comunicação.

## 3. Teste de Balanceamento (Balancing Test)
**Os interesses do controlador prevalecem sobre os direitos do titular?**
- **Natureza dos Dados:** Dados profissionais de contato (Business to Business). Nenhum dado sensível é tratado (Art. 11 LGPD).
- **Expectativa do Titular:** É razoável esperar que profissionais com contatos públicos recebam propostas comerciais B2B relevantes para o seu negócio.
- **Impacto:** O impacto é mínimo (recebimento de mensagens de texto).
- **Salvaguardas:**
  - Opt-out imediato implementado e aplicado compulsoriamente (anti-requisito R-024).
  - Transparência de origem de dados, caso questionada (R-064).
  - Silêncio imediato e handoff ao humano quando requisitado.

**Conclusão:** O tratamento baseia-se solidamente no legítimo interesse do controlador, sem ferir direitos fundamentais do titular.
