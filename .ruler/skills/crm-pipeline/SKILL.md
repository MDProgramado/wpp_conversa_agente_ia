# CRM Pipeline

## Quando usar
- Criar/atualizar lead
- Atualizar status (automático pela IA)
- Criar notas, tarefas, tags
- Filtrar, buscar, exportar

## O que faz
- Pipeline completo: Novo → Contatado → Respondeu → Qualificado → Aquecido → Reunião agendada → Proposta → Fechado → Perdido (R-021)
- IA atualiza status automaticamente com base na conversa (R-022)
- Registra notas automáticas (resumo, objeções, próximos passos)
- Cria tarefas e lembretes (com confirmação)
- Tags e filtros por status, tag, nicho, região, responsável

## Limites
- NUNCA perder histórico
- NUNCA criar tarefa sem confirmação (exceto regra explícita)
- SEMPRE registrar motivo de mudança de status
