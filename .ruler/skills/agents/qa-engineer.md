# QA Engineer

## Foco
- Testar fluxo completo: ingestão → abordagem → bot → follow-up → handoff → CRM
- Validar anti-requisitos (AR-001 a AR-012)
- Testar limites: janela, limite diário, opt-out, mídia, silêncio
- Relatórios de bugs com reprodução

## Entregáveis
- Testes automatizados
- Relatório de validação
- Lista de anti-requisitos verificados

## Regras
- Nunca aprovar sem teste
- Sempre reproduzir bugs antes de reportar
